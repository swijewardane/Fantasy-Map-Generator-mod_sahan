# My Personal Mod of Azgaar's Fantasy Map Generator

Hey there! This is a work in progress right now, but the aim of this project is to add region-generation functionality to Azgaar's FMG, 
utilizing Louvain/Leiden clustering algorithms on map cells, weighted according to pre-existing attributes (state, biome, culture, religion, elevation, etc.)

Currently the repository contains:

-The forked and modded directory from [https://github.com/Azgaar/Fantasy-Map-Generator]
-A prototype code in Python
